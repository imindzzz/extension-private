# 2026-11-16

## 技术栈迁移：Plasmo 0.65 → WXT 0.21

**动因**：`npm view plasmo time.modified` = 2025-05-17，已停更一年半；WXT 仍在发版（2026-10-26）。

**版本矩阵决策**

| 包                | 选型                                                       | 原因                                                                                 |
| ----------------- | ---------------------------------------------------------- | ------------------------------------------------------------------------------------ |
| wxt               | 0.21.5                                                     | 需要 Node >= 22（本机 22.22.2 满足）                                                 |
| vite              | 8.3.8                                                      | `@wxt-dev/module-react` peer 允许 ^8.0.0-0                                           |
| react / react-dom | 19.3.1                                                     | —                                                                                    |
| typescript        | **5.9.3**（非 7.0.2）                                      | `typescript-eslint@8.72.2` peer 是 `>=4.8.4 <6.1.0`，升 TS 7 会让 lint 直接失效      |
| eslint            | 10.15.0 + typescript-eslint + react-hooks 手写 flat config | 没用 `@antfu/eslint-config`：它缺 optional peer 时会交互式提示安装，非交互环境会卡住 |

**结构变化**

- `src/contents/*.tsx` → `src/entrypoints/*.content.ts`，文件名即 manifest 声明，不再手写 manifest。
- 删除 plasmo 模板残留（`inline.tsx`、空 `PlasmoInline` 组件、注释掉的 anchor）。
- `copyToClipboard` / `secondToTime` 迁入 `utils/copy-to-clipboard.ts`、`utils/duration.ts`，纯函数抽离并配 Vitest。
- bilibili UI 从 `getOverlayAnchor` + 负 margin hack 改为 `createShadowRootUi` + `inline` + `autoMount`。
- 图标用 ffmpeg 从 512 源图生成 16/32/48/96/128 五档（PowerShell `Add-Type` 被安全策略拦截，改用 ffmpeg）。

**顺带修复**

- 分 P 累计进度语义 bug：原实现先累加当前项再判断 break，导致"正在看第 3P"时把第 3P 全长算进已看；新 `sumWatchedBefore` 只累加 `index < activeIndex`。
- 时长解析支持 `h:mm:ss`，且 `parseInt` 失败返回 null 而不是 NaN 污染总和。
- `blacklist` 内容脚本保留骨架但去掉每页 `console.log`。

**React 19 注意**：`react-hooks@7` 新增 `set-state-in-effect` 规则，effect body 内同步 `setState` 会报错；改为 `useState` 惰性初始化 + 仅 interval 回调里 setState。

**验证**：`wxt prepare` → `tsc --noEmit` → `eslint` → `vitest`(15 passed) → `wxt build`(495.9 kB) 全通过；`modern-web-guidance legacy-scan` 0 findings。

**外部工具**

- `chrome-extensions` 技能装到 `~/.workbuddy/skills/`（来源 GoogleChrome/modern-web-guidance，CLI 默认只装 modern-web-guidance，chrome-extensions 需从仓库手动取）。
- `~/.workbuddy/mcp.json` 增加 `chrome-devtools`（`--categoryExtensions --autoConnect`），未在此次会话启用。

## 输出目录合并（dev 与 build 共用）

`wxt.config.ts` 设 `outDirTemplate: '{{browser}}-mv{{manifestVersion}}-dev'`，去掉 `{{modeSuffix}}`，
让 `npm run dev` 与 `npm run build` 都写 `.output/chrome-mv3-dev`，Chrome 只需加载一次该目录。

**注意** `outDirTemplate` 是相对 `outDir` 的，写成 `.output/xxx` 会得到 `.output/.output/xxx`。

**实测差异**（这是不能把 dev 版当日常版的原因）：

|                    | dev 版                                                           | build 版               |
| ------------------ | ---------------------------------------------------------------- | ---------------------- |
| 体积               | 3.6 MB                                                           | 496 kB                 |
| `content_scripts`  | **manifest 中不存在**，由 background 运行时用 scripting API 注册 | manifest 静态声明 4 组 |
| `host_permissions` | 额外含 `<all_urls>`、`http://localhost/*`                        | 无                     |
| CSP                | 放开 `localhost:3000`                                            | 默认                   |
| background         | 有（reloader）                                                   | 无                     |

**已验证**：build 覆盖 dev 目录时 `background.js` 被清空；dev 覆盖 build 目录时 `background.js` 重新出现，双向切换无残留。

**风险**：`wxt clean` 会删 `.output` 导致 Chrome 报扩展损坏；dev 与 build 不可同时运行；合并后无法并存两份产物。

## 黑名单功能 + 管理界面 + zip 备份

**规则模型**：只看域名（不看协议/端口/路径），`*` 通配任意字符。`*.example.com` **不含裸域**，
单 `*` = 全拦（测试里特意固定了这个语义）。`normalizeDomain` 兼容裸域名、带协议 URL、带路径输入。

**存储**：`@wxt-dev/storage` 的 `defineItem`，两个 key：`local:blacklist`、`local:settings`。
跨 context（popup / content / manager）通过 `item.watch()` 实时同步，改动无需广播消息。

**拦截实现**：`document_start` + 遮盖式，不是网络层阻断。
- 先注入 `html{visibility:hidden}` 再异步读 storage，未命中立即移除；带 800ms watchdog，防 storage 卡死导致永久白屏。
- UI 准备好后才解除 visibility，把「页面露出」压缩到一次同步 `mount()` 内。
- 拦截页**手写 DOM 不引 React**：该脚本注入所有页面，React 会让每次导航多解析 ~230KB。
- 样式用 `?inline` 打进 JS，避免 `web_accessible_resources` 向全站暴露可探测文件（实测 WAR 只剩 bilibili.css）。

**导入导出**：fflate，zip 内 `manifest.json` + `blacklist.json` + `settings.json`。
- 导入按 basename 匹配，兼容压缩包带一层目录。
- 校验：非 zip / JSON 损坏 / schemaVersion 过高 → 抛 `ImportError`；非法域名规则丢弃并统计 `skipped`；
  设置走白名单字段 + 范围校验（`playbackStep` 限 0~4）。
- 合并模式按 `domain` 去重，保留 base 顺序。

**管理界面**：`entrypoints/manager/`（原 options 改名），`manifest.options_ui.open_in_tab = true`，
WXT 的 `getURL` 类型只认 `/manager.html`。三个 tab：黑名单 / 设置 / 数据。

**新增权限**：`storage`、`contextMenus`、`activeTab`（弹窗读当前 tab 域名，避免用 `tabs` 触发浏览历史警告）。

**测试**：46 个用例（域名匹配、zip 往返、非法输入、部分备份、版本拒绝、合并去重）。
